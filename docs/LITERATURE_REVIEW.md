# Literature Review and Research Tool Review

Research date: 2026-10-25. This is an initial source review, not a claim that all global papers/videos have been exhaustively catalogued. The workflow should append dated source notes as new sources are independently checked.

## Core scientific literature
1. **Moskowitz, Ooi & Pedersen (2012), “Time series momentum,” Journal of Financial Economics 104(2), 228–250.** DOI: https://doi.org/10.1016/j.jfineco.2011.11.003. The paper documents time-series momentum in diverse futures and forwards over 1–12 month horizons. Relevance: motivates past-return direction features. Limitation: a multi-month diversified-futures finding does not establish a weekly NIFTY spot edge.
2. **Bailey, Borwein, López de Prado & Zhu (2017), “The Probability of Backtest Overfitting,” Journal of Computational Finance.** DOI: https://doi.org/10.21314/jcf.2016.322 ; accessible summary: https://escholarship.org/uc/item/4w1110bb. Relevance: many strategy trials can make ordinary holdout evaluation unreliable; use a locked holdout, experiment registry and multiple-testing discipline.
3. **MAPIE / conformal prediction.** https://github.com/scikit-learn-contrib/MAPIE and https://mapie.readthedocs.io/en/stable/. Describes conformal methods for uncertainty estimation and risk control. Use only if time-series assumptions are tested; do not assume conformal coverage under arbitrary market non-stationarity.
4. **ARCH package / financial volatility modelling.** https://github.com/bashtage/arch. Provides ARCH/GARCH-family models including GARCH, EGARCH, TARCH and HAR. Relevance: volatility/regime features. Conditional volatility is not, by itself, a directional predictor.
5. **PySR symbolic regression.** https://github.com/astroautomata/PySR ; paper https://arxiv.org/abs/2305.01582. Supports interpretable symbolic-expression discovery. Relevance: bounded expression search can propose compact features. Limitation: search flexibility creates data-snooping risk; search only inside training folds, constrain complexity, then evaluate once on locked data.
6. **TradingAgents.** https://github.com/TauricResearch/TradingAgents ; paper/preprint link: https://arxiv.org/abs/2412.20138. Multi-agent financial analysis framework with specialized technical/fundamental/sentiment and risk roles. Use as hypothesis/source-synthesis support, not as ground truth or backtest validator.
7. **Quantevolve.** https://github.com/tarsyang/quantevolve. Upstream describes an evolutionary quantitative-trading strategy development system. Use to inspire bounded candidate generation. Evolved candidates must pass fold separation and multiple-comparison gates; no automatic strategy is presumed profitable.
8. **AstraQuant Agent.** https://github.com/0xethanq/astra-quant-agent. Upstream describes an autonomous crypto trading system with multi-LLM analysis and deterministic risk control. Architectural inspiration: separate model proposals from deterministic risk/data checks. It is crypto/OKX-oriented and not directly reusable as an NSE strategy; review its AGPLv3 plus Commons Clause licence before copying code.
9. **tick.** https://github.com/X-DataInitiative/tick. Python statistical learning with emphasis on time-dependent modelling. Possible advanced temporal models, but optional due compatibility/maintenance and small-sample constraints.
10. **TradingView Pine Script.** Official docs: https://www.tradingview.com/pine-script-docs/ ; public scripts: https://www.tradingview.com/scripts/. Relevance: inspect established open-source indicator ideas and implement Pine prototypes. Community scripts have varied licences and quality; record authorship/licence and do not copy code without checking terms.

## Public and official data sources to search
- NSE NIFTY 50 derivative expiry specification: https://www.nseindia.com/static/products-services/equity-derivatives-nifty50. The current weekly expiry is Tuesday and expiry moves to the preceding trading day when Tuesday is a holiday.
- NSE contract specifications: https://www.nseindia.com/static/products-services/equity-derivatives-contract-specifications.
- NSE all reports / historical indices / India VIX: https://www.nseindia.com/all-reports.
- India VIX methodology: https://www.nseindia.com/static/products-services/indices-indiavix-index. India VIX reflects option-implied expected volatility, not return direction directly.
- Candidate intraday data: https://github.com/technovusin/nifty50-historical-data. Its README reports 1-minute NIFTY 50 OHLC from 2017 and 15-second bars from September 2026, and lists known data quirks. The repository publishes MIT licence, but underlying market-data redistribution rights and accuracy still need verification.
- Options complement: https://zenodo.org/records/10899828 (NIFTY spot/futures/options one-minute dataset, 2017–2020; Zenodo record lists about 320.9 MB). Verify schema, lineage, rights and contract-expiry alignment.
- Public options candidate: https://huggingface.co/datasets/rissin/nse-options-intraday. Source page describes daily historical index options and intraday data from 2024 onward; large (~2.3 GB); selectively download partitions only if needed.
- FII/DII and daily reports: prefer NSE/exchange reports; record publication date/time to avoid using values published after the forecast time.
- Global cross-market features: daily/overnight returns for US indices, Asian benchmarks, USD/INR, crude and gold can be considered if point-in-time timestamps allow. Do not merge a daily close published after the NIFTY forecast time.

## Research gap and contribution
The narrow question differs from generic long-horizon price prediction. It targets the sign of one precise cycle return between an intraday anchor and expiry close, across a major expiry weekday change. A useful contribution is a clean label specification, actual-calendar alignment, rigorous time-ordered comparison, uncertainty reporting, and a negative-result publication if no edge survives. There is no evidence reviewed here that already proves a profitable NIFTY weekly-expiry-direction strategy under this exact target and Paytm Money costs.
