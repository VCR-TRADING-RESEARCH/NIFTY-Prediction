HOW TO INTERPRET THIS

What this forecast means

01

UP / DOWN is spot direction

It predicts whether the NIFTY 50 spot close at the target expiry is above or below the 10:00 anchor. It does not choose strikes or estimate options P&L.

02

Score is not certainty

The score is the ExtraTrees model's estimated UP-class score. It has not been established as a reliable, calibrated chance of success.

03

Validate before using it

The reported 61.25% accuracy came from an 80-observation chronological holdout. The 95% Wilson interval was about 50.3%–71.2%; source and anchor limitations remain.

04

It is not an options backtest

Before using it to choose a multi-leg options strategy, validate option quotes, fills, bid/ask spreads, slippage, and date-effective Paytm Money and exchange charges.
