HOW TO INTERPRET THIS

What this forecast means

01

UP / DOWN is spot direction

It predicts whether the NIFTY 50 spot close at target expiry is above or below the selected 10:00 Dhan anchor. It does not choose strikes or estimate options P&L.

02

Score is not certainty

The score is the newly fitted ExtraTrees model's UP-class score. It is not a calibrated chance of success.

03

Validate before using it

Earlier walk-forward results are exploratory. Each live request retrains on available settled labels; neither the historical score nor the new output proves profitability.

04

It is not an options backtest

Before using it to choose a multi-leg options strategy, validate option quotes, fills, bid/ask spreads, slippage, and date-effective Paytm Money and exchange charges.
